# grill 論点 G — project の名（scribe と folio を合わせた新しい名・名は可変）

- 出自: 持ち主の裁定（2026-09-25・逐語は台帳へ）= 台帳を起こす前に project の名を考え直す。scribe3 には folio v2 を統合するので scribe と folio を合わせた新しい名にしたい。project 名・plugin 名・CLI 名は scribe2 と同じように可変にしておきたい。
- 状態: 裁定済み（tsuzuri・CLI tz・prefix t3・ADR-6）

## 1. 事実（verified・2026-09-25）
- scribe2 は器の名を 1 つの定数から導き、marker（`name=scribe2`）・git の設定（`<NAME>.stateDir`）・plugin・着地の印（trailer）の名がそれに従う（scribe2 host-init.md §2・folio2 design-note schema の trailer_name_source「器の名前の定数」）。v3 も同じ形にする = 名は値で、code は名で分岐しない（憲法 N-7・N-3 の趣旨）。
- 名の衝突を実測した（crates.io の `cargo search`・host の PATH・GitHub の `gh search repos`・host の project dir）。

| 候補 | 由来と意味 | scribe + folio の当てはまり | CLI 名 | 衝突（実測） |

## 2. s3 席の推奨
**tsuzuri（綴）**。scribe（綴る）と folio（綴じる）を 1 語で持ち、日本語で書く設計文書と釣り合う。CLI `tsuzuri`・plugin `tsuzuri`・台帳の prefix `tz`（床の裁定 id の形 `[a-z]\d-…` には数字が要るので `t3`）。crates.io の同名 crate は publish しない限り衝突しない（workspace は publish = false）。
次点 = chancery（裁定面の意味が強い・英語の 1 語で綴りやすい）。

## 3. 名を可変にする形（裁定の後に ADR で決める・論点 A の要件へ）
- 器の名は 1 つの定数（build 時の値）から導き、marker・git の設定・state dir・plugin 名・CLI 名・着地の印・台帳の prefix・session の名が全部それを使う。名を変えるのは定数 1 か所と、置き場の改名の手順（init が受け持つ）。
- repo の dir 名・state dir 名・tmux の session 名・登録 row は改名の影響を受けるので、名が決まったら scribe2 席と手順を合わせて 1 度で移す（可逆 = 移動）。

## 4. 問い（1 問）
新しい名を **tsuzuri（綴）** にしてよいか。台帳の prefix は `t3`（床の裁定 id の形に合わせて数字を含める）。別の候補（chancery・quire・amanuensis・bindery・foliant）や、あなたの案があればそれで進める。

## 5. 裁定（2026-09-25T00:39Z（名）/ 00:42Z（prefix）・逐語は台帳へ）
- 名は **tsuzuri**。CLI の名はもっと短く。prefix は CLI の名と揃える。dir の改名・scribe2 の設定の直し・席の立て直しが要る、と持ち主。
- s3 席の読み: 床の裁定 id の形は「英字 1 + 数字 1 + 横線」を code に焼いている（folio2 floor_adr.rs の RULING_PATTERN・has_ledger_id）。prefix = CLI 名にするなら (a) CLI 名に数字を含める（t3 など）か (b) 床の形を prefix から導く値にする（folio2 の小さな便）。(b) が「名は値」（N-7）の趣旨に合う。

## 6. 問い（1 問・CLI と prefix の綴り）→ 裁定済み
- 持ち主の裁定（2026-09-25T00:5xZ・逐語は台帳へ）: CLI は tz、prefix は t3。3 は v3 であることを残す印。00:42Z の「揃える」はこれで上書き。床の直し（folio2 f2-648.203）は不要になった。

CLI の名と台帳の prefix を **tz** に揃えてよいか（2 字・PATH と host に衝突なし。台帳 id は `tz-07l.214` の形）。床の裁定 id の形は folio2 に小さな便で直してもらう（(b)）。folio2 の便を待ちたくなければ **t3**（数字入り・今の床を通る）。次点は tsu（3 字・読みやすい）。
