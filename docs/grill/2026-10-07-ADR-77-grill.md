### 誤って止める側（偽の陽性）

- **F1 lens の揺れ**: 器の設計は「lens の verdict は同じ材料でも揺れる（PASS ↔ FAIL）ので、材料不変の再 intake を 1 回も許さない形は採らない」と書く（R/scribe2/docs/design/contract-source.md:223・V）。数えを契約の替えで戻さないと、揺れの 2 回で構造の原因の無い bead が止まる（I）。直し: 型 other と unparsed を P-10.3 の bead ごとの断りから外し（型ごとの bead をまたぐ数えには入れる）、揺れの率を撤退の鍵に足す。
- **F2 編集の時点の検査を罰する**: P-10.2 は「契約の置きが断られたとき」も落ちに数える（W/constitution.diff.md:100・V）。preflight（R/scribe2/crates/scribe2/src/pipe/cli/preflight.rs:187・V）と契約の置きの照らしは、起草の時に何度も撃って直すための口（contract-source.md:224 の (4)「planner が edit time に測る」・V）。これを数えると、条 P-14 の向き（編集の時点で止める・R/design-intent/constitution.yaml:370-371・V）と逆に、席と係が preflight を撃たなくなる（I）。さらに **L3 の新しい preflight の断り（write-set の外の使い手）に、索引が教えたとおり write-set を足して直す正しい手が、2 回目で止まる**（I）。直し: P-10.2 の落ちから preflight と契約の置きの断りを外し、**便を求めた受付の断り**だけを数える。
- **F3 一度の誤りの正しい直し**: 語の定義（W/vocabulary.diff.md:5）は「構造を替えずに目の前の契約…だけを直して通すこと」で、原因がその契約の一度きりの誤りでも場当たりに入る（I）。直し: 定義に「同じ型の落ちをまた生む原因を残したまま」を足す。字の案: 「落ちた事を、同じ型の落ちをまた生む構造（型・数え・置き場・手順・上限）を替えずに、目の前の契約・頼みの文・閾値・file だけを直して通すこと。」

## 2. r386 の grill の点 (a)〜(f)（攻める点 2）

### (a) N-3（例外の口）— 判じ: **直す**

- 構造の札（P-10.3）: 札の先が「その落ちの型を狙い、落ちの後に着地した行」に限られるなら、札は例外でなく前提の充足（構造の行の着地を待つ依存）であり、N-3.1（R/design-intent/constitution.yaml:686「無効化の旗・今回だけの口」・V）に当たらない（I）。ただし今の字は E5 のとおり先を選び替えられ、判断の記録を名指せば常設の口になる（I）。E5 の直しを入れて通る。
- 壊れの直しの札（P-10.4）: 形も照らしも無い自己申告の札は、停止線に対する「今回だけの口」そのもの（V: 形の定義 0・I: 当たり）。直しの字の案（P-10.4）:
  「初回で着地した便の率が規則の表の行 R-46 の線を下回っているあいだ、器は、構造の札か、器の記録に在る壊れを名指す壊れの札を持たない便を断る。」
  mechanism の注に「壊れの札の先は器の event log の main の赤の event か、着地した行の id とその後に落ちた歯の名で、器が実在を照らせない札は断る」。

### (b) P-19.2（器が採否を代行しない）— 判じ: **通る（1 つ条件）**

- 断りと次の 1 手（P-7.3・R/design-intent/constitution.yaml:276・V）を出すだけで、どの構造の直しを採るかは席と持ち主に残る。今の器の SameKindRepeated と同じ型の断り（R/scribe2/crates/scribe2/src/pipe/refuse.rs:201-210・V）で、前例がある。停止線の値も持ち主の裁定（P-17）で、器は裁定の値を執行するだけ（I）。
- 条件: P-10.5 の「器が memo を開き直す」は台帳の状態の替えで、P-19.1 の「知らせる」（constitution.yaml:442・V）を 1 歩越える。開き直しが「状態を開くだけで、直すかと何で直すかは決めない」と mechanism の注に書けば通る（I）。E4・E6 の照らしは字面と記録の実在だけを見る機械の照らしで、中身の良し悪しを器が判じないことも注に書く。

### (c) 停止線が壊れの直しまで止めて詰まる — 判じ: **直す**

- 壊れの札が定義されないままだと、器は fail-closed で壊れの直しも断る（詰まる）か、何でも通す（口になる）かのどちらか（I）。(a) の直しで解く。
- E9 の自壊・自縛も同じ点の内。窓を本数にし、判じられない間は前の判じを保つ。
- 撤退 (2)（停止線の断りが 1 以上で、同じ窓に構造の札の行の着地が 0）は詰まりの測りとして良いが、鍵が 2 つの組み（§5 の P-4.2 の形で書けない）。

### (d) 型の粒度 — 判じ: **直す**

- 違う原因を同じ型に寄せる: FindingKind の other（受け皿）と、gate の FAIL を 1 型にすること（clippy・歯・flip-check・main の赤が 1 つに寄る）（I・FindingKind の 7 語は contract-source.md:210・V）。直し: other と unparsed は bead ごとの断りから外す（F1）。gate は落ちた段の名を枝にする（閉じた列挙・P-1.6）。
- 同じ原因を別の型に割る: E3（連続か累計かが字に無い）。直し: 累計と字で決める。
- 便の問いの止まり: 入れるのは正しい（CTX3 の問い 20 件が write-set の閉包・ADR-77.yaml:20・D）。ただし問いを 1 型にすると中身の違う問いが寄り、しかも問いを数えると、黙らないこと（前文の順位の 2 位）と逆に「問わせない契約」を書く誘いになる（I）。直し: 問いの止まりは bead ごとの断りから外し、型ごとの bead をまたぐ数え（§1 の P-10.6 案）にだけ入れる。
- 切り替え: M1 の着地の時に器が過去の event を読むと、契約を替えて数えが戻っていた bead が一度に R-3 を越えて止まる（I）。直し: 「数えは M1 の着地の後の落ちから」と M1 の字に書く。

### (e) K5 の注だけの変更と A-2.2 — 判じ: **通る（字を 1 か所直す）**

- 直す字: K5 の新しい注「1 位の場当たりの修正の禁止は条 P-10 が…規範文と機構を持つ」（ADR-77.yaml:112）は、P-10 の live が M1 で床が「機構がまだ無い条」に数える（drafts/w387a/check4.log の末の行「P-10（M1）」・V）のと合わない言い過ぎ。字の案: 「1 位の場当たりの修正の禁止は条 P-10 が規範文を持ち、その機構の在る無しは条 P-10 の mechanism の欄に従う」。
- mechanism_live_rule の出所の直し（P-4.2 → P-7.2）は、この記録が P-4.2 を新しく置く事と結ぶので、同じ版に載せてよい（通る）。持ち主の問いでは別の 1 項として見せる。
