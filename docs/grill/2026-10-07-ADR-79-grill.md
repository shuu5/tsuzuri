### 4b. 契約の行の式（係 w409a）との比べ（席の足しの頼み）

材料: drafts/w409a/w/notes.md の要点・決めた事・外した形・書き漏れの表・懸念。w409a の suffix.py は撃っていない（予算の 90% を越えたため）。w409a の数は D として扱う。

| 差の出所 | 2 本の穴 ＋ 5 file の印つきの use と検査の mod の doc の注 24 ＋ review.rs の 4 | 2 本の穴だけ（review 806・move_proof 607） |

- **直す M9（ADR を w409a の式に揃える・D）**: 揃える訳は次の 4 つ。
  - (a) 行頭の `}` で閉じを読む形には抜け道が残る。器には fmt の門が無い（w409a の命令 4・5、rc 1 で 0 件）。検査の mod の閉じの `}` を字下げして置き、その後ろに本番の `impl X { … }` を置くと、その impl の列 0 の `}` が mod の閉じに読まれ、本番の code が歯の区間に入る（D）。w409a の括弧の深さでは起きない。
  - (b) 全体に倒す但し書きは、歯の区間を空にして閉包と審査から歯を消す（§4）。w409a は区間を連続の `&str` に保ち、derive.rs の 7 か所の呼び手を替えない。
  - (c) 数は真の区間に近い（＋4 対 ＋32）。
  - (d) 写しの一覧が M1 で私が挙げた漏れ（env_reads・rules_wired・collide）を含む。
  - 揃える時に ADR で直す所: 決定 (1) の式の字・K1 の写しの一覧・F3 と plain の数（90,453 → 90,425・余地 −453 → −425）・決定 (4)-3 と撤退が名指す数えの script（count2.py → w409a の suffix.py の写し）・note の 49 行の字。
- **問う（w409a の式の残りの抜け道・U）**: 字句の読みが Rust の字句の規則を外れる形が残る。照らす形は次の 3 つ。
  - 入れ子の塊の注（`/* /* */ */`。Rust は入れ子を許す）
  - 寿命の `'a`（字の `'a'` と取り違えやすい）
  - byte の字と生の byte の字（`b"…"`・`br#"…"#`）
  - w409a の見本（fx.py）がこれらを持つかは見ていない（U）。歯に入れるよう契約に問う。
- **直す M10（どちらの式でも書かれていない 2 点・V は w409a の notes の字）**:
