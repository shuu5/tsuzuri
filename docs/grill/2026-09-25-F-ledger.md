## 2. 決め（deduced）
1. **scribe3 に自分の台帳を持つか**: 持つ。器の便・裁定 id・brief の「台帳の現在値」の 3 つが要る。決定はしごは「既に在るか」で止まる（bd がある・scribe2 と folio2 と同じ形）。
2. **prefix**: `s3`。床の裁定 id の形に合い、scribe2（s2）・folio2（f2）と並ぶ。
3. **形**: scribe2 と同じ（埋め込み dolt・issues.jsonl を tracked・remote は repo に remote が無いあいだは無し）。folio2 の sync.remote は repo の公開の裁定（A-1）の後に足す。
4. **前の版の台帳**: scribe2（s2-…）と folio2（f2-…）の台帳は読み専用の前の版として残す。移さない（v3 は合流の世代でも、台帳の便は各 repo の仕事なので、閉じるまでそれぞれの repo で動く）。v3 に関わる memo（s2-07l.214・.590・.604・.608）は s3 の台帳に「出所」として id で指す（写さない）。
5. **裁定 id の記帳先の切り替え**: 台帳が立った後の裁定は s3 の台帳の notes に s3 席が直接記帳する（scribe2 席の代筆を終える）。既に発効した記録（ADR-2〜ADR-4・憲法 v1.0）の承認欄は s2-07l.214 を指したまま（凍結後は変えられない・出所として正しい）。ADR-5 は依頼済みなので s2 で発効させ、以後は s3。
6. **run の終端（v2 の残り 7）**: v3 の器は便の終端を台帳の event（close と notes の記帳）で持ち、札の不在で推さない。これは論点 B の裁定面と器の設計（面の便の後）で扱う。
