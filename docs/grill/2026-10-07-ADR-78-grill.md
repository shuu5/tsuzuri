## 要点

- 判じの総まとめ: **直す 13・持ち主に問う 3・通る 5**。重い順の上位は次の 4 つ。
  1. **(F1) teams を切る設定はその場で効き、器の終わりの門は `team-lead` 宛ての SendMessage を要る**。公式は「新しい session は要らない・env は保存した時に走っている session に当て直す」と書く。切ってから B1 が入るまでの間、係は在りもしない宛先へ知らせを送れと止められる。teams を 0 にする前に、B1 の bin の入れ替えと手引きの替えを着地させることを、決定 (2)(9) の固い前提として書く。
  2. **(F2) §3.4 の「席の session は 2026-09-24 に起き、効いていない commit は 12 本」は誤り**。席の process は 2026-10-06T06:32:04Z に起きた（ps）。効いていないのは 6 本で、その中に hooks.json の 1 本が在る。立て直さなくても、`/reload-plugins` で plugin の agents と hooks を当て直せる（公式）。生きた係が 0 の今すぐ当てるのがよい。「効いているか」を照らす口が無いことは、行の候補（B16）にする。
  3. **(F4) U の字は誤り**。design は「走り中の subagent への配りを公式は書いていない」と言うが、公式の字には「走っている間に届けるには agent ID で宛てる」と「起こした agent からの途中の向け直しを指図として扱う」が在る。届くことは導ける（D）。分からないのは、届いた字をいつ読むか（U）だけである。
  4. **(F5) 持ち主は「teammate 機能やサブエージェント機能を十全に使える」ことを求めた**。teams を切るとこの求めの前半を捨てることになる。ADR はこの食い違いを持ち主に正面から問い、失う物 9 つ（§2）と、teams を残したまま係を subagent で起こす中間の道（呼びに `isolation` を付ける）を選ぶ案として並べる。
- (l) の数の照らし: M-e（usage_day.py）は合う（10-06: 115 体・18,210,945 token・usage.json が無い係 26 体・V）。H1（returns.py）は撃ち直せなかった。席の session の記録（c8c93f14-e9f4-402d-b353-24a9f7f2f494.jsonl）が口座の dir の下に見つからず、rc は 1。撤退の測りを他の者が撃ち直せないこと自体が欠けである（F9）。
