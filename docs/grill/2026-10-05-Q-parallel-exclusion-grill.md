## 1. 初版への攻め（判じ: 直してから出す）

- 致命 1 つ（K1）: 再 gate の面（器の land.rs の DETECTION_SCOPE と宣言の crate-roots の和）の外の path では、字は当たっても組めない物を main の前に落とす受け皿が無い。これは判断の記録 ADR-33 の決定 (12) の理由そのもの。→ 交わる path が全部面の中に在る時だけ通す形に直した。器の行 v-roots で scribe2/crates/ が面に入ると字を替えずに広がる。
- 要直し 9 つ:
  - R1 待ちの和は依存だけでなく全部の和 385 時間（依存 360・連鎖 282＝73%）。
  - R2 縮む待ちは和で、壁の時計ではない。
  - R3 書きの見込みの式を本文の中で閉じる（見込み＝並んだ組 × 今は追随しない率 × 4〜6 GB・上の縁＝今追随しない便の数 × 4〜6 GB）。撤退 (イ) を見込みの外の 80 GB/日に。
  - R4 器を書く便を 1 本ずつにするのは席の作法でなく ADR-33 の決定 (12)。
  - R5 着地の列は審査役を撃たない。
  - R6 runner のずれは字の条件では守れない。測った（差の file 177 本のうち着地を見つけた 162 本で、差の外を書かなかった行 153 本＝94%）。
  - R7 撤退の (ア)(ウ)(エ) を数えられる字に（原因を問わない・stale は分ける・bead の付記の印 omitted-dep で数える）。
  - R8 改める物に受入の基準 AC1014・待ちの理由の閉じた列・条 P-17.4 を足す。
  - R9 両方が同じ名を足す組（vocab.rs は vocab.json の鍵を黙って後勝ちで入れる）は歯が拾わない。→ 器の判じで同じ宣言の名を足す組を断る形（甲）に。
- 軽い 4 つ: 3 本以上の積み・判じの費用と一時の dir・判じの置き場（overlaps の後に呼ぶ 1 本の関数）・平易さ。L3（置き場だけ = どうしの交わりを通す例外）は席の決めで入れていない。
