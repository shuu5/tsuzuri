## 初版への攻め（判じ: 直してから出す）

- 致命 1 つ（F1）: 席の流れの道具の呼びを「持ち主の裁定 id を持つ計画の file」で通す形は、前の問いで退けた案（流れの道具の中の係に門が効くかが分からない）の穴を開け直す。門は裁定 id の字を見るだけで台帳の実在も中身も照らさず、席が計画に前の裁定 id を書けば 7 日の断りと一緒に既定で開く。→ 流れの道具の呼びを全部断る形に直した。7 日の断りの例外は、裁定 id が台帳の問いの裁定の定型行に在り、その問いの本文が群の id を名指す時だけにした。
- 要直し 9 つ:
  - R1 「固い分 約 9 万」は固定の費用でない（起こしの 1 歩は 約 2 万・冷えて 約 4 万）。語を外し、上限が仕事の途中で尽きる形に書き直した。丙を退ける差は 3 倍でなく 約 14.5 万（見立て）。
  - R2 得の見せ方。13/14 は群の中の比べで、1 体との比べは数の直し 2 つと精密化 1 つ。1.6 倍は攻めの係が少なく出た値で、上限いっぱいなら 約 2.2 倍。調べの群は「得が無い」でなく「得を測る前に止めた」。
  - R3 試しの割り（器の event log を 2 体が読んだ）は path の重なりの断りで起こせない。割りの重なりは主張の id で断り、読む path の重なりは数えるだけにした。
  - R4 分からない主張の一覧の形を誰も決めていなかった。攻めの係が一覧の file を書き、門が行を数える形にし、1 体 6・全部で 18 までの溢れの断りを足した。
  - R5 前の答えに無い新しい決め（6 つ）を問いの推奨に列挙し、概要の ③ で名指した。
  - R6 「割り当ての外を読めない」は言い過ぎ。断るのは読みの道具だけで、命令と検索の道具の読みは止めない。
  - R7 値を規則の表に置かない理由（欄の決まりの除外＝AI の費用）と、値を替えるのは判断の記録で、を書き、この検証の記録を grill の欄に添えた。
  - R8 規則の表の行 D-1 に合わせ、計画の file に係ごとのモデルを持たせ、違うか欠けた起こしを断る。
  - R9 3 体を一度に起こすので止める線は起こしを止めず撤退の数えにだけ効く事と、試しの群が止める線の 約 82% だった事を書き、届いた時から席が群を起こさない天井を足した。
- 軽い 10: 概要の選び肢の漏れと誤字・語の言い替え・平易文の丸め・決定の番号の曖昧さ・受入の見本の漏れ・日付の固さ・起草の記録の誤り・読み直しの最悪・名で呼び合う形の係の分からなさ・ノートの行の余地。直した物は判断の記録 ADR-61 と問いの本文に映した。
