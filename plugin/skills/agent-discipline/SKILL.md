# 係の規律（agent-discipline）

この手引きは天井で、決まりの正本は門と歯である（条 N-2）。各決まりの末の括弧は、破りを止める門の名か、門が無く自分で守る「天井だけ」。手順と前例は同じ dir の reference.md に在り、要る時に読む。

## 頼みと終わり

- 頼みの頭は 4 行（予算・組み・対象・出す物）で、群の検証役は 5 行目に群の行を持つ。係の名は起こしの名（門 agent-spawn）
- 生きた係と対象が重なる起こしは起きない（門 agent-spawn）
- 席は流れの道具（Workflow）で係を起こさない。使うなら持ち主に問う（門 agent-spawn）
- 頼みの全文は起草の置き場の <名>/brief.md に在る。圧縮で頼みが見えなくなったら読み直す（天井だけ）
- 出す物を自分の <名>/w/ の下に書き、出力の path を SendMessage で席に知らせてから終える（門 agent-stop）
- 済みと書く前に、撃った命令と rc を出す物に書く（天井だけ）

## 予算

- 予算は新しく読み書きした量（input と cache_creation と output の和）で数え、自己申告で数えない。測りの注ぎ（50・75・90%）が来たら調べを広げず、分かった所を書く（門 agent-meter）
- 100% を越えたら、自分の w/ への書きと席への知らせだけをして終える（門 agent-guard）

## 置き場

- 写しは起草の置き場の直下にだけ作る（器の門 drafts_guard）
- repo と台帳は読むだけ。commit・push・台帳の書きは頼みが許す時だけ（天井だけ）
- reset --hard・branch -D・force push を撃たない。file は消さずに mv で退ける（器の門 host_guard）
- pkill -f を撃たない。止めるのは自分が起こした pid だけ（天井だけ）
- 公開の file に口座の名・host の名・ほかの project の名・持ち主の逐語を書かない（天井だけ）

## 検査

- 背景で撃った物の終わりは、知らせを待たず log の rc と ps で見る（天井だけ）
- 数は完全な記録からだけ書き、途中の log や見立てを丸めない（天井だけ）
