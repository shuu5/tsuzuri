やさしく言うと
「あとから戻せない判断」の記録（いま 6 本）を、入口・憲法・要件書と同じ見た目のページとして機械に作らせる決め方の記録です。記録 1 本につきページ 1 枚で、入口ページの棚から 1 本ずつ開けます。中身は元の記録の欄をそのまま写し、「採用した案」と「退けた案」を同じ形で並べ、承認の言葉と日付もそのまま出します。まだ承認されていない記録には「提案中」の印が付きます。ページを作る仕組みは今の手書きのままで、外の道具（テンプレート）には移りません。移るかどうかは、前の判断の記録（ADR-5）が「ページの種類が増えるときに聞く」と決めていたので、この記録で一緒にあなたに聞きます（見た目だけを直した回数は 0 回なので、移らない方をおすすめします）。要件書には「判断の記録のページを作る」という要件を 1 つ足し、「作らない」の行から外します。

何が問題か
持ち主は 2026-09-18 に「ADRも人が読むページの生成に入れて」と命じた（台帳 f2-648 notes・対話面 R-8）。planner 席が同日に確かめた事実は次のとおり。(1) 判断の記録の正本は adr/ADR-1〜ADR-6 の 6 本（1 判断 = YAML 1 file・欄の決まりは adr/schema.yaml）で、人が読む面は暫定の読み物（preview/readable.html・folio render の生成物）にしか無い。この読み物は器（scribe2）の s2-07l.467 の着地後に退役を持ち主に問う予定で、生成器の 3 面（入口・憲法・要件書）と見た目も部品も揃っていない。(2) 要件書の版（v1.3）の範囲（scope）の「作らない」の行に「判断の記録（ADR）と設計ノートの生成」が在り、判断の記録の面を作る要件（FR）と受入基準（AC）は無い。要件書の改訂が要る。(3) 入口の正本（index.yaml）の棚は判断の記録の行を持つが、行の「無いとき」の文言（まだ戻せない判断は無い）だけで、6 本の記録へ辿る導線が無い。(4) 判断の記録 ADR-5 決定 (3) は生成器を手書き（外部の部品を足さない・部品目録を型で閉じる）と定め、撤退条件 ① は「面の型が 3 面から増える便を設計するとき、テンプレートの案へ移るかを持ち主に問い、増えた後の面の型の数と見た目だけを直した便の数を台帳から数えて添える」と定める。数えた値 = 増えた後の面の型 = 4（設計ノートの面が M1 で来れば 5）・見た目だけを直した便の数 = 0（台帳の閉じた便の見出しに「見た目」を含むものは 0 本）。(5) 判断の記録 ADR-6 決定 (3) は支度表を 4 面目にせず入口の面の節にしたが、判断の記録は 6 本で各本が案の表・撤退条件・承認欄を持ち、条・要件・rules 行の id から 1 本ずつ辿られる（P-5.2・入口の正本の矢印「憲法を改訂する」）ので、節では収まらない。分岐は 4 つ在り、面の型の数と受入を決めるので、便を起こす前に持ち主に問う。
何を決めたか
判断の記録の面を次のとおり定める。(1) 面の型 = 4 面目「判断の記録」を足す。判断の記録の正本（adr/ADR-n.yaml）1 本から人が読むページ 1 枚を組み、ページの名は id（ADR-n）に揃える。一覧（どの記録が在るか・状態・日付）は入口の面の棚の行から出し、棚の行から各ページへ辿れる（入口の正本には数と一覧を書かず、生成のたびに正本の置き場から数える・P-6.3）。(2) 生成器 = 手書きのまま（判断の記録 ADR-5 決定 (3) を維持）。足す部品は判断の記録の節（見出しと状態の印・問題・決定・案の表〔採用と却下・理由〕・根拠の id の並び・撤退条件・改訂の一覧・承認欄・平易文・帰結）を出すのに要る最小で、部品目録（parts.json）へ足す。部品の追加の判断の記録は本判断がそれに当たる（P-2.4）。図の型は増やさない。(3) 中身 = 正本の欄から逐語で組む（P-6.1）。案の表は採用と却下を同じ形で並べ、採用だけを大きく見せない。根拠の id（条・要件・rules 行・判断の記録）は各面の該当の場所へ跳ぶ導線とし、行き先の無い id は「まだ分からない」の印で出す（P-4.2）。状態が提案中（proposed）の記録は「提案中・拘束力なし」の印を見出しに出し、廃止（retired）の記録は後継の id（superseded_by）への導線を出す。承認欄は逐語と日付をそのまま出す（P-12.2）。(4) 受入 = 4 面のすべての部品の名札（class）が部品目録に在ることを機械が数えること（AC2 の形を 4 面に広げる）と、生成した判断の記録の面を持ち主が開いて読んで承認すること（AC5 の形・逐語と日付を記帳）。(5) 順序 = 本判断の発効と要件書の次の版（v1.4）（判断の記録の面の要件 FR16 と受入基準 AC14 を足す・範囲（scope）の「作らない」の行から判断の記録の生成を外す）を同じ取り込み（PR）で → M1 の便の列（便 23 → 便 24）の後に、部品目録と生成器の面の便 → 入口の棚の導線の便 → 歩いて読む承認（walk）→ 暫定の読み物の判断の記録の部分の退役は器の s2-07l.467 の着地後に A-1 で問う。便は直列で運ぶ。(6) 撤退条件 ① の問いは本判断の案 b として持ち主に出し、持ち主が案 a を承認したら判断の記録 ADR-5 の撤退条件は捨てず、設計ノートの面（5 面目）を設計するときに再び問う。
案（採用は 1 つ）
手書きの生成器のまま判断の記録の面を 4 面目として足す〔採用〕 判断の記録 ADR-5 決定 (3) を維持し、判断の記録の面を出す生成の関数と部品を手で書き足す。部品目録に足す部品は最小で、閉じた一覧の一致は既存の検査で守る。 — 見た目だけを直した便は 0 本で、手書きの手間がテンプレートの手間を上回った証拠が無い。依存を足さず（A-3.1 の確認と R-6 の予算が要らない）、部品目録を型で閉じる守りがそのまま効く。M1 の便の列を止めない。
テンプレートの外部の部品（crate）へ移り、4 面をテンプレートの file で書く〔退けた〕 判断の記録 ADR-5 の案 b。生成器を捨て、外部の部品（テンプレートの crate）が正本の値を差し込む形へ移り、既存の 3 面も書き直す。 — 判断の記録 ADR-5 の撤退条件 ① が問う案。数えた値（見た目だけを直した便 = 0・面の型 = 4）では移る根拠が無く、移るには依存の追加の確認（A-3.1）・予算（R-6）の決定・部品目録を検査で守り直す新しい判断の記録・既存 3 面の書き直し（便 3〜4 本）が前置になる。設計ノートの面（5 面目）を設計するときに再び問う。
暫定の読み物（preview/readable.html）を判断の記録の面として残す〔退けた〕 描画の命令（folio render）が出す暫定の読み物をそのまま判断の記録の人が読む面とし、生成器の面は足さない。 — 人が読むページはすべて 1 つの生成器から出す（P-2.1）に反する。読み物は部品目録の外で見た目が 3 面と揃わず（P-2.3）、器の s2-07l.467 の着地後に退役を問う予定のもの。
判断の記録を入口の面の節として出す（判断の記録 ADR-6 の支度表と同じ形）〔退けた〕 4 面目を足さず、6 本の判断の記録を入口の面の 1 つの節に並べる。 — 判断の記録は各本が案の表・撤退条件・承認欄を持ち、条・要件・rules 行の id から 1 本ずつ辿られる（P-5.2）。入口の面の節では 1 本ずつの行き先が持てず、6 本を並べると入口の案内が読めなくなる。支度表（1 枚の短い表）とは長さも役割も違う。
