## 持ち主へ問う項

### 🔴 問 1. 要件書 第 1.34 版（版 B）と天井の正本 v0.14 を発効する

**やりたいこと。** M3 で何を作り、どこで「終わった」とするかを要件書に書く。判断の記録 ADR-16 が決めたことを、要件と受入基準の形に移すだけである。

1. 要件書に「M3 で作る／作らない」の節を足す（中身は ADR-16 決定 (1) の写し）。
2. 新しい要件 4 本（FR22 骨格の命令・FR23 列の根の表・FR24 始まりの凍結・FR25 値域の部分集合）と、受入基準 9 本（AC19〜AC22 = 4 本の歯・AC23〜AC25 = M3 の出口の判定点 ①〜③・AC26 と AC27 = FR22 の 2 つの規範文の歯）を足す。
3. FR3 と FR10 の注に 1 文ずつ、FR11 の確かめ方の指し先に AC24 / AC25、表紙の題に M3 を足す。語彙の命令名の一覧に `init` を足す。
4. 天井の正本を v0.14 にする＝要件書の scope か scope_m1 を読む 3 観点（忠実さ・読みやすさ・文書どうしの整合）が scope_m3 も読む。足さないと、天井の審査役に渡す材料の束から M3 の範囲の節が「落とした節」として外れ、4 観点のどれも M3 の範囲を読まない。
5. 憲法の条 P-6 の機構の注 1 か所に、導出物の検査の命令（要件 FR11 の独立の命令 folio derive --check・便 119 で 2026-09-24 09:14 JST に着地〔main c33ee44〕）を名指す 1 句を足す。改訂 f で、FR11 の契機（when）の「名は便で決める」を命令の名 folio derive --check に置き換え、FR11 の注に着地の事実を足し、語彙の「命令と旗」に derive を足した（便 119 の着地に追随・要件の状態は変えない）。改訂 g（席の裁定・09:5x JST）で、FR22 の注に「生成区間の導出は graph.yaml も書く」の 1 文を足した（便 125 の起草の実測: 書かないと folio schema --check が止まる・規範文は変えない）。条文は変えないので条文の改訂（条 A-2）ではない。

**理由。** ADR-16 決定 (7) が「版 B は ① の後に出す（持ち主の承認）」と決めており、① にあたる便 117 と、面が節を描く便 118 が着地した。版 B が無いと、便 ②〜④（列の根の表・始まりの凍結・値域・骨格の命令）が契約表の要件の欄に指す要件を持てない。判定点 ③ は folio2 の外の事実なので、利用者の台帳の記録が在れば着地・無ければ「まだ分からない」とする（ADR-16 決定 (5)）。

**代替案。**
- **(A) 範囲の節だけを先に発効し、要件は便ごとに足す。** 承認の回数が便の数だけ増え、便 ② の契約が指す要件がその時点で無い。
- **(B) 判定点を受入基準にせず、範囲の節の字だけで持つ。** 判定点が機械の読む行（受入基準の id）を持たず、便の契約や台帳から id で指せない（条 P-5.2）。

**コスト。** 承認 1 回（要件書と天井の正本を同じ承認で）。**既存の要件の規範文・平易文と受入の判定の式は 1 字も動かず、番号は新しいものだけ。** 床は合格で、歯は全部通る（下の床の節）。

**推奨 = 1〜5 をまとめて発効する。** ADR-16 の承認で決めたことの写しで、新しい決めごとを持ち込まない。

## 席の裁定（持ち主に問わない分け方）

順序や分け方だけを問う問いは持ち主へ出さない（`.beads/PRIME.md`）。次の 2 つは席が決めた（裁定 id = 席・2026-09-24 07:1x JST・改訂 b の依頼）。

1. **決定 (2)(キ)（器の導出 file を版管理の根で解く）は FR26 にせず、FR10 の注の 1 文に留める。** 理由: ADR-16 決定 (2)(キ) が「この形は便 ④ の契約に書く」と定めており、要件の規範文でなく便の契約が持つ形だから。
2. **判定点 ①〜③ は受入基準 3 本（AC23〜AC25）のまま。** 理由: 判定点 ③ は folio2 の外の測定値で、① や ② と形が違うので 1 本に畳まない。

改訂 d で、独立の検証の問う 3 つも席が決めた（裁定 id = 席・2026-09-24 07:2x JST・改訂 d の依頼）。

3. **scope_m3 の入口の文から版の番号を外す。** 理由: 決定 (1) の原文に番号は無く、一括 15 の問 7 が案 B なら第 1.34 版の番号がそちらに要る。
4. **判定点 ③ の測定値は AC25 の字（器の受付が導出物を読んで通した記録・利用者の台帳）を正とする。** 理由: 決定 (1) ③ の字で、器の受け口（s2-07l.473）の着地は前提であって測定値ではない。AC25 の注にその 1 文を足した。一括 15 の側（問 7 の案 A の測定値の字）は席が直す。
5. **FR22 の 2 つの規範文の歯を今の版で受入基準 AC26・AC27 として足す。** 理由: 字の出現の数と 1 行の中身は機械で決定的に数えられる（条 P-3.1）ので、便 ④ の契約へ回さず要件書に置く。FR22 の確かめ方の指し先にも足し、両向きの対称を揃えた。
