## 2. 持ち主の疑いへの答え

**疑い: 「根本的な設計の部分は古い scribe2 が作っていてそこに大量に問題が隠されている」。**

答えは「半分そのとおり」である。設計文書と契約を書いたのは器ではなく席（AI）だが、**器の制約が席の書く形を決めた**跡が §1-b のとおり残っている。隠れていた問題の実例は、今日の切りの直前に 1 つ出た＝便 98 の契約は「天井の印も門も変わらない」と書いたが、印の側は「写しは全観点で同一」という便 98 以前の前提を持っており、凍結の土台では 4 観点の写しが偶然そろっていたので歯が拾えず、印が書けなくなった（便 104 で是正）。**契約が主張する「当たらない」の範囲を、凍結の土台で確かめる歯が無かった**のが穴で、同じ形の穴は §1-b の pin の歯 65 本の外側にも在りうる。

一方で、設計文書（憲法・規則・要件書・語彙・判断の記録）は 26 周の天井と床で毎回検査され、意味の食い違いはその都度一括で直してきた。**設計文書の中身をリファクタリングする必要は、いま見つかっていない。** 直すのは次の 4 つの層である。

1. **module の境界**（実装）: 上限で割った file を責務で割り直す。
2. **契約と歯の書き方**（開発の作法）: 数値でなく手順・性質で書く。契約の PR の前に受付を撃つ。
3. **台帳**: 開いた bead を今の実態に合わせ、ADR-13 の残り 4 本の行き先を決め、復元の入口を 1 枚にする。
4. **要件の穴**: FR11 / FR13 / NFR1 / FR21 の状態を要件書に明示し、いつ埋めるかを決める。

### 🔴 5. 判断の記録の未消化の決定（ADR-11 ⑥⑦⑧・ADR-13 の 4 本）

〔理由〕発効した判断の決定に bead が無いのは、台帳が判断の記録を追えていないことの実例（P-5.4 の台帳の役割）。⑤-2 と ⑩ は周の回数と門の止め方を変えるので、持ち主の目的関数（精度・実時間）に直接効く。
〔代替案〕(A) ADR-13 の 4 本を「M3 へ」と注で印し、起票しない。(B) ADR-11 の 3 本を閉じて判断の記録の注で「取り下げ」と記帳する。
〔コスト〕起票 7 本。便は §3-c の 5・6 番目（時期は §3-c の 1〜4 の後）。
〔推奨〕全部起票し、順を §3-c のとおりにする。

### 🔴 6. 契約と歯の作法を規則にする（D-13）
