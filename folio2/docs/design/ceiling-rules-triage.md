## 引き金の便の契約の要旨

- **名と大きさ。** 「引き金の便」は判断の記録 ADR-26 決定 (3) の実装の便の仮の名である（段階の M とは別）。大きさは M。
- **題。** 周の引き金から判断の記録の状態の欄と発効の絞りを外す（ADR-26 決定 (3)・ADR-18 決定 (1) の改訂）。
- **いま起きていること。** 引き金の要約値は `crates/folio/src/gate.rs` の関数 effective_adrs が、状態が発効か廃止で承認欄を持つ判断の記録だけを拾い、`crates/folio/src/ceiling.rs` の定数 TRIGGER_ADR_FIELDS（8 欄・状態を含む）を取る。定数 TRIGGER_ADR_STATUS は発効の値域そのもので、床の木の trigger.adr.status と天井の正本の生成区間の写しに出る。判断の記録の発効（状態の変化と承認欄の記帳）だけで引き金の要約値が動く。
- **変えること。** TRIGGER_ADR_FIELDS から状態の欄を外して 7 欄に。TRIGGER_ADR_STATUS と床の木の trigger.adr.status の葉を外す。effective_adrs の絞りを外し、判断の記録の置き場の直下の .yaml（欄の決まりの file を除く・名の byte 順）を全部拾う。trigger_note の字を「adr は状態を問わず fields」に。
- **write-set の見込み。** crates/folio/src/ceiling.rs・crates/folio/src/gate.rs・design-intent/ceiling.yaml（生成区間だけ・`folio schema --write` の出力）・crates/folio/tests/gate.rs（歯を足す）・crates/folio/tests/schema_docs.rs（天井の正本の生成区間の行数の定数）・tests/fixtures/ の天井の正本の写し（生成区間を持つもの）と印の写し stamp-pass / stamp-fail / stamp-unknown.yaml の引き金の要約値（凍結 anchor の測り直し）。本数と行数は受付の時点の main で数える（行 D-13）。
- **歯。** (1) 提案中の判断の記録の決定の字を変えると引き金の要約値が変わる。(2) 同じ記録の状態を提案中から発効へ変え承認欄を足しても引き金の要約値が変わらない。(3) 門の 9 場合（受入基準 AC18）は変わらない。
- **門。** 書き換える file の一覧に天井の正本が在るので門の対象である。生成区間は引き金の欄（重さ・文書の一覧・観点の行）ではない。移行の周の印が新しければ 通す を返す。
- **着地の後。** 引き金の要約値の関数が変わるので、本流の印は着地の時点で古くなる。行 D-16 により、それだけでは周を起こさない（次の節目の周が新しい印を書く）。
