## 1. 設計

### (a) いま起きていること（実測・数え方は (i)・参考値は base での測り）

`crates/folio/src/parts.rs` は 2 つの役を同居させている。

1. **部品の検査の命令の口**（`folio parts` の --print と --check。部品目録と組み立て時の写しの一致・面の class・部品の名札・行内の様式を数える）。責務の層は **2 検査する**。
2. **部品目録の閉じた一覧の取り込み**（組み立ての script `build.rs` が部品目録 `design-intent/preview/parts.json` から導出して組み立ての出力の置き場に書いた source 1 本を、公開の区切り catalog として取り込む。部品・図の型・棚の型・行内の様式に許す性質の閉じた一覧と、上限 3 つと図の型の名札の定数）。正本を型に直したものを置くだけで、何も検査しない。責務の層は **1 読む**。

2 の側を 11 file が `parts.rs` 経由で名指している。面の 8 file（`face.rs`・`face_adr.rs`・`face_note.rs`・`face_index.rs`・`face_constitution.rs`・`face_srs.rs`・`face_srs_items.rs`・`face_srs_rtm.rs`・層 4）は部品の一覧を、判断の記録と設計ノートの床と床の検査の口（`adr.rs`・`note.rs`・`check.rs`・層 2）は図の型の一覧を、設計ノートの床はさらに密度 profile の一覧を読む。どれも下向きか同じ層の辺で、決まりには反していない。ただし閉じた一覧は検査の層に在ることになる。

**層が上がる辺 `parts` → `face` の出どころは、閉じた一覧ではない。** `parts.rs` の単体の歯の区画に在る**凍結の針** parts_derived_limits_and_figure_labels_are_frozen_needles（便 52）の 1 本が、本文の中で面の file の名 4 つ（上限 3 つの名と図の型の名札の名）を取り込んでいる。この針は、面の file の名を通して読んだ上限が 7・4・4 で名札が便 52 の前の手書きの 5 対と順まで同じこと、導出した定数の側も同じ値であることを測る。区間の外に定義がある名を列挙した結果（ADR-15 決定 (5)）、閉じた一覧の source（組み立ての出力・410 行）は区切りの名を 1 つも名指さず（取り込みの行を持たない）、層が上がる辺はこの針だけから生えていた。

便 107 の後の 層が上がる辺は **8 本**（参考値）。境界の歯の file の凍結した一覧と一致している。

### (b) 直す先 — 閉じた一覧を新しい `catalog.rs`（層 1 読む）へ、針を `face.rs`（層 4）の歯の区画へ、どちらも字を変えずに移す

**1. 閉じた一覧の取り込み**を新しい file `crates/folio/src/catalog.rs` へ移す。移すのは、組み立ての出力を取り込む 1 文（`include!` の 1 行）と、使わない定義を咎めない許し（`dead_code` の許し）の 2 つだけである。区切りの外側に付いていた許しは、file の頭の内側の許し（憲法の値域の置き場 `constitution_enums.rs` と同じ形）になる。掛かる範囲は同じ（区切りの全体）。区切りの説明の 1 行は、新しい file の頭の注 3 行に書き直す。組み立ての script も、組み立ての出力の file 名も、出力の中身も 1 字も変わらない。

**2. 凍結の針 1 本**を、本文と名を 1 字も変えずに `face.rs` の単体の歯の区画の末尾へ移す（説明の注 2 行・歯の印 1 行・本文 31 行と空行 1 の計 35 行）。針が測るのは面の file の名（上限 3 つの名と名札の名）なので、責務の上でも面の file の歯である。針が使う導出した定数の 2 つ（上限の表と図の型の名札の表）は `parts.rs` の取り込みから区画の glob で届いていたので、`face.rs` の歯の区画に新しい file から 2 つを取り込む 1 行を足す。針の本文が区切りの名で呼ぶ上限 3 つは、`face.rs` が新しい file を取り込む行（区切りの自分自身の名を含む）から区画の glob で届く。

区間は字を変えずに移す。起草役は写しの repo で diff の足した行と消した行を多重集合で照らし、足した行と消した行の多重集合の一致は 36 行で、そのうち 35 行が**針（空行を含む）で、`parts.rs` の消す塊と `face.rs` の足す塊は並びまで一致する**。残る 1 行は `catalog.rs` の空行が `parts.rs` の消える空行と対になったもの。閉じた一覧の取り込みの 1 文は字下げだけ違う。区間の外の名を使っていないこと（ADR-15 決定 (5) の列挙）は組み立てで確かめた（`cargo build --all-targets` を 0 警告で通した）。

**名指しの行だけを書き換える 11 file**。閉じた一覧を `parts.rs` 経由で名指していた file は、どれも新しい file を直接名指すように取り込みの行を書き換える。
