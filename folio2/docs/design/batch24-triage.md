### 判定 1 ＝ 8 つ目の場合の名札を平易文の字にする（規範文の「同じ根」は変えない）

- **所見の指摘は正しい。** 名札「write-set と --dir を同じ根で照らせない」は、要件書の面の語彙に無い英字の `--dir` を持つ。語彙で「根」を引くと、意味の違う「列の根」（凍結 anchor の憲法の写しの列の最初の 1 枚）に着く。同じ受入基準 AC18 の平易文と要件 FR20 の平易文は、既に「同じ起点で照らし合わせられない」と書いている。
- **名札の字は要件 FR20 の平易文の字に揃えた。** 「書き換える file の一覧と設計文書の置き場を同じ起点で照らし合わせられない」である。AC18 の平易文は「置き場」とだけ書くが、名札の並びの 1 つ目が「設計文書の置き場の file を触らない」なので、同じ並びの中で置き場の字を揃えた（迷った点 1）。
- **場合の数と中身は変えない。** 8 場合・照らせないとき 2（まだ分からない）のままである。歯は名札の字を読まない。`crates/` と `tests/` のどこにも名札の字は無い（`grep` で 0）。歯 `crates/folio/tests/gate.rs` の `f142_` の 2 本が確かめるのは門の理由の行の字（「--dir と write-set の根が違う」「--dir が今の dir の下に無い」）で、実装の定数の字である。要件書の名札を変えても歯と食い違わない。
- **規範文の「今の dir を同じ根として照らす」は変えない。** 規範文はその文の中で write-set（書き換える file の一覧）と --dir と根の読み方を定めている。規範文は周の引き金で、所見も規範文を挙げていない。FR20 の注の第 1.46 版の段に、規範文の「同じ根」と平易文と名札の「同じ起点」が同じものだと書いた。
- **FR20 の注の第 1.45 版の段の「8 つ目 = write-set と --dir を同じ根で照らせない → 2」は変えない。** 第 1.45 版の直しの記録の字である。

### 判定 2 ＝ ADR-24 の「同じ根」と「同じ起点」は平易文と注でつなぎ、決定は触らない

- **決定の字は変えない。** ADR-24 は 2026-09-26 に発効した判断の記録で、決定の欄は周の引き金である。発効した決定の本文は書き換えない作法がある（ADR-24 決定 (4)・ADR-21 決定 (6)・判断の記録の欄の決まりの revises_note）。「同じ根」を「同じ起点」に替えるのは字句の直しでも決定の本文の書き換えで、自分自身の決定を改訂の欄で変える口は無い。
- **つなぎは平易文と注に置いた。** 平易文は判断の記録の面の頭に出て、持ち主が最初に読む。「直した後の門は…添えます。」の次に「『同じ起点』は門を実行する場所のことで、一覧の path も置き場の path もそこから読みます。この判断の決定・文脈・改訂の欄は、同じものを『同じ根』と書きます（凍結した憲法の写しの列の『列の根』とは別のものです）。」を足した。注の言い換えの行（置き場の path = --dir など）にも同じ写しを足した。
- **決定を触る形は採らなかった。** 触るなら、ADR-24 を改訂の欄で変える新しい判断の記録が要る。字句のつなぎのために判断の記録を 1 本起こすのは費用が重く、平易文の 1 文で読み手の取り違えは閉じる（迷った点 2）。

### 判定 3 ＝ 憲法 N-4 の平易文は改訂に当たらないので本一括に入れる

- **条 A-2.2 に照らした。** 条 A-2.2 は「条文（id・見出し・規範文・段・縛る相手）と schema 節・前文が 1 文字も変わらない変更を改訂として扱わない」。平易文はこの一覧に無い。N-4 の機構の注も、数える母集団を「schema 節・前文・各条の id / title / statements / tier / binds」とする。平易文だけの直しは改訂に当たらず、憲法の版は上がらない。周の引き金（`TRIGGER_CONSTITUTION_ARTICLES` = id・title・tier・binds・statements）の外でもある。
- **先例は一括 15 である。** 一括 15（本流 `73a6bf7`・`docs/design/batch15-triage.md` の忠実さ F-5 と 🔴 問 5）が条 A-1 の平易文を同じ扱いで直した。その仕分けは「一括 10・11 で条の平易文を同じ承認で直した先例」と書き、憲法の平易文の直しは承認欄を持たないとした。**依頼の書いた先例「一括 20 / 22」には憲法の平易文の直しは無かった**（`git show` で憲法の差分を確かめた・迷った点 3）。
- **字は規範文の範囲に合わせた。** 規範文 N-4.1 は対象を「条文の改訂」に限る。平易文を「この 3 つが揃っていない憲法の条文の書き換え（改訂）は、機械が止めます。」にした。「憲法の」で文書を、「（改訂）」で規範文の語を示した。前文と schema 節の変更も機構の母集団に入るが、規範文が「条文の改訂」とだけ言うので、平易文は規範文の範囲に留めた。
