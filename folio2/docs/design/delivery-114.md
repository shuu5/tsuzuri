1. **正規化行と余地**: 空行を含む全行を数え、1 行の字数（Unicode の字の数）が 120 を超える行は 切り上げ(字数 ÷ 120) − 1 だけ足す。余地 = 1,500 − その値。
2. **辺と層の向き**: 設計ノートの冒頭の走査の式に字面の剥がしを足したもの（注釈と字面を剥がし、絶対の道と括り書きを解き、入口だけ接頭辞なしも数え、自分自身は数えない）を当て、層の割り当てで 下向き / 同じ層 / 上向き に分ける。境界の歯そのものがこの式を持つので、`cargo nextest run -p folio --test modules` が数え直しである。起草役の独立の走査では、base が 51 file・246 辺（下 173・同じ層 73・上 0）、本便の後が 52 file・249 辺（下 174・同じ層 75・上 0）だった（参考値）。消える辺は 1（`schema.rs` から `note.rs` への下向き）、足す辺は 4（`note.rs` と `schema.rs` から新しい file への下向き 2、新しい file から床の木の型と部品目録の閉じた一覧への同じ層 2）。`note.rs` から床の木の型と部品目録の閉じた一覧への辺は残る（検査の本体が床の突き合わせと図の型を使う）。
3. **区間の純度と見え方と歯の名**: base と本便の後の diff の足した行と消した行を多重集合で照らす（一致は 394 行＝区間の 428 行のうち見え方を広げなかった 393 行と空行 1 行）。移動でない行は、足した側が (g) の 53 行、消した側が (g) の 37 行である。見え方を広げた 35 行は、印を外すと消した側の 35 行と字が一致する。見え方は src 全体で、道具の中で公開の印（`pub(crate) `）を含む行と、行頭の公開の印（空白の後の `pub `）の行と、再輸出（`pub use` と `pub(crate) use`）の行と、`use super::*;` のほかの super:: の名指しを base と比べる（154 → 189・369 → 369・3 → 3・0 → 0・参考値）。道具の中で公開の印の増分 35 は、定数 31 本と型そのもの 1 と必須の欄 1 と method 2 である。設計ノート §4-d の便 114 の値 39 + 2 との差（参考値）は、§4-d の測りが置き場と違反の種別の 5 本も区間に入れて広げたこと、床の木だけが使う 3 本と任意の欄も広げたこと、型そのものと 2 つの method を数に入れていなかったことによる。本便は 5 本を `note.rs` に残し、3 本と任意の欄を私のまま残し、型と method を数に入れる（拡大が少ない向き・§0 の 設計ノートからの逸脱）。足した行に super:: が無いことも diff で確かめる。歯の名は `cargo nextest list --workspace` を base と並べ、sort して比べる（違い 0）。
